# LastWave → Flutter Migration Plan

## Overview
Migrate the native Android app (Kotlin + Jetpack Compose + ExoPlayer) to Flutter (Dart) with cloud iOS builds via GitHub Actions + Codemagic.

---

## Architecture Mapping

| Android Component | Flutter Equivalent | Effort |
|-------------------|-------------------|--------|
| **Jetpack Compose UI** | Flutter Material 3 + Custom Widgets | High |
| **ExoPlayer (Media3)** | `just_audio` + `audio_service` + `audio_session` | Medium |
| **Room Database** | `drift` (SQLite) or `isar` | Medium |
| **DataStore Preferences** | `shared_preferences` + `flutter_secure_storage` | Low |
| **Hilt DI** | `get_it` + `injectable` (or Riverpod) | Low |
| **Coroutines/Flow** | Dart `Stream`/`Future` + `rxdart` | Low |
| **Kotlin Serialization** | `json_serializable` / `freezed` | Low |
| **OkHttp/Retrofit** | `dio` + `retrofit.dart` | Low |
| **WorkManager** | `workmanager` (bg tasks) | Medium |
| **Foreground Service** | `audio_service` (iOS: background audio) | Medium |
| **MediaSession/Notifications** | `audio_service` + `media_notification` | Medium |
| **Android Auto** | Not directly portable (separate iOS CarPlay) | Skip v1 |
| **USB Audio (C++ JNI)** | Platform channels + native code | High (defer) |
| **Cast SDK** | `google_cast` (Flutter) | Medium |

## Phase 4: Cloud CI/CD Pipeline (Week 1, parallel)

### GitHub Actions + Codemagic Setup

```yaml
# .github/workflows/flutter.yml
name: Flutter CI/CD

on:
  push:
    branches: [main, develop]
    tags: ['v*']
  pull_request:
    branches: [main]

jobs:
  analyze:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: subosito/flutter-action@v2
        with: { flutter-version: '3.24', channel: 'stable' }
      - run: flutter pub get
      - run: dart analyze --fatal-infos
      - run: dart format --output=none --set-exit-if-changed .

  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: subosito/flutter-action@v2
        with: { flutter-version: '3.24' }
      - run: flutter pub get
      - run: flutter test --coverage
      - uses: codecov/codecov-action@v4

  build-android:
    runs-on: ubuntu-latest
    needs: [analyze, test]
    steps:
      - uses: actions/checkout@v4
      - uses: subosito/flutter-action@v2
        with: { flutter-version: '3.24' }
      - run: flutter pub get
      - run: flutter build apk --release --split-per-abi
      - run: flutter build appbundle --release
      - uses: actions/upload-artifact@v4
        with: { name: android-build, path: build/app/outputs/ }

  build-ios:
    runs-on: macos-latest
    needs: [analyze, test]
    steps:
      - uses: actions/checkout@v4
      - uses: subosito/flutter-action@v2
        with: { flutter-version: '3.24' }
      - run: flutter pub get
      - run: flutter build ipa --release --export-options-plist=ExportOptions.plist
      - uses: actions/upload-artifact@v4
        with: { name: ios-build, path: build/ios/ipa/ }

  # Codemagic alternative for iOS (free tier, faster)
  # Triggered via Codemagic webhook on tag push
```

### Codemagic Config (`codemagic.yaml`)
```yaml
workflows:
  ios-release:
    name: iOS Release
    max_build_duration: 60
    instance_type: mac_mini_m1
    environment:
      flutter: stable
      xcode: latest
    scripts:
      - name: Get dependencies
        script: flutter pub get
      - name: Build IPA
        script: flutter build ipa --release --export-options-plist=ExportOptions.plist
      - name: Publish to TestFlight
        script: |
          xcrun altool --upload-app -f build/ios/ipa/*.ipa \
            -t ios -u $APP_STORE_CONNECT_API_KEY_ID -p $APP_STORE_CONNECT_API_KEY
    artifacts:
      - build/ios/ipa/*.ipa
    publishing:
      app_store_connect:
        api_key: $APP_STORE_CONNECT_API_KEY
        api_key_id: $APP_STORE_CONNECT_API_KEY_ID
        issuer_id: $APP_STORE_CONNECT_ISSUER_ID
```

## Cloud iOS Build - Zero Mac Required

Once Flutter code exists:
1. **Push to GitHub** → GitHub Actions runs tests + Android build
2. **Tag release** → Codemagic (free tier) builds iOS IPA + uploads to TestFlight
3. **No Mac needed** - all cloud

**Codemagic Free Tier:** 500 build minutes/month, M1 Mac Mini instances
**GitHub Actions:** 2000 min/month free, includes `macos-latest` runners

## Risk Mitigation

| Risk | Mitigation |
|------|------------|
| InnerTube API changes | Abstract behind interface, test with recorded responses |
| Lyrics provider APIs | Keep modular, easy to swap |
| Audio quality (bit-perfect) | Use `just_audio` with `audio_session`; defer USB to v2 |
| iOS background audio limits | `audio_service` handles properly; test early |
| Kotlin → Dart bugs | 1:1 port with shared test vectors; property-based tests |
